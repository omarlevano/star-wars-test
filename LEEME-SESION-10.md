# Sesión 10 · Aspectos avanzados de CSS

Página nueva: **pages/holocron.html** («Holocrón» en el menú). Estilos en **css/sesion10.css**.

| Tema | Dónde |
|---|---|
| Degradados radiales (dos soles) y lineal (cielo) | `.portada-holo` |
| Degradado lineal (hojas de los sables) | `.hoja` |
| Degradados repetitivos | mango de los sables y radar del mapa |
| SVG con `<img>` | `media/img/planeta.svg` |
| SVG dentro del HTML | mapa de la galaxia |
| Texto en columnas | `.texto-columnas` |
| Fuente descargada con `@font-face` | Orbitron en `media/fonts/` |
| Fuente importada con `@import` | Share Tech Mono (Google Fonts) |
| em y rem | `.ep span`, `.ficha-planeta`, `.f-datos` |
| Selectores por atributo | `.sable[data-color="…"]`, `a[href^="http"]`, `a[href^="mailto:"]`, `a[href$=".html"]` |
| `::before` y `::after` | comillas de `.cita`, línea bajo los `h2` |
| CSS Grid: 3 × 3 con `repeat()` y `fr` | `.grid-saga` |
| CSS Grid con áreas (header, aside, article, footer) | `.ficha-planeta` |
