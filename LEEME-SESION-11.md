# Sesión 11 · Animaciones, media queries y plugins de jQuery

Página nueva: **pages/cronologia.html** («Cronología» en el menú).
Estilos en **css/sesion11.css**, impresión en **css/impresion.css** y código en **js/cronologia.js**.

| Tema | Dónde |
|---|---|
| `@keyframes` animando `background-position` | estrellas del hiperespacio (`viajar`) |
| `@keyframes` con porcentajes + `perspective` | texto de apertura que se aleja (`alejar`) |
| `animation-play-state` | el texto se pausa al pasar el mouse |
| `animation-direction: alternate` | brillo del botón sable (`zumbido`) |
| `animation-fill-mode` | entrada de las secciones (`aparecer`) |
| Media queries con `and` + `orientation` | celular en horizontal |
| Media query en `<link media="print">` | `css/impresion.css` (prueba con Ctrl + P) |
| `prefers-reduced-motion` | apaga las animaciones si el sistema lo pide |
| Plugin FontFlex | título «Cronología de la saga» |
| Plugin bxSlider (banner) | galería de la saga |
| Plugin SweetAlert2 con `.then()` | «Elegir mi lado»: respuesta distinta para cada botón |
| Plugin Timelinr | las nueve películas por año de estreno |
